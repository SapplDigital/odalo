¿Se puede empezar con un solo servicio?

Con la estructura de planes, sí: los planes se construyen unos sobre otros, así que se podría empezar con una parte y añadir otras después. El alcance se propondría y se acordaría antes de empezar.

¿Se puede trabajar con una web existente?

Normalmente sí. Un primer paso propuesto sería revisar tu web actual y anotar qué conviene mantener y qué mejorar.
