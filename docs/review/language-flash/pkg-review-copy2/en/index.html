FAQ
Can a project start with one service?

With the plan structure, yes: the plans build on each other, so a project could start with one part and add others later. The scope would be proposed and agreed before work starts.

What is included in each plan?

The full list is on the plans page, with a comparison and what is not included. Some commercial conditions are still to be confirmed.

Is advertising spend included?

In the plans, no: ad spend is paid directly to Google or Meta; the plan does not include that budget. The 360 plan is quoted individually.

Can the work start from an existing website?

Usually, yes. A proposed first step would be to review your current website and note what to keep and what to improve.

What are the example projects?

Casa Almina, Tidewell and Brindle Pantry are three self-initiated concepts for fictional businesses. They show how websites, local visibility, content and advertising can work together. They are not client work and show no client results.

Which languages is this website available in?

This website is available in English, Spanish and German. Which languages a specific project would cover is agreed before the quote.

Can a plan be changed?

We expect so, but change and cancellation conditions are not defined yet. They would be set out in a proposal.

What does the free audit include?

The free audit is an Odalo offer; its detailed scope, format and response time are not confirmed yet. The form on this demo only simulates a submission: it checks the fields, shows a simulated confirmation and keeps your entries visible. Please use sample details: nothing is sent.
