## Follow-up: DE 1024 Video-open overshoot (2026-10-29) - Sonnet 5.5, no Git writes
**Finding.** The earlier "CPU flake" label was not sufficient. A per-frame in-page recorder (rAF, DE 1024, click on Video) shows REAL transient text spill in the first painted frames of the ~360 ms morph: the opened piece's text is laid out for its final size while its box still has the old size, so text ran up to ~445 px below the box over neighbouring pieces (settled within ~250-480 ms). It is NOT caused by the polish: a pre-polish build (copy of the source with only the polish edits reverted, built outside the repo, no Git) shows the same pattern (up to ~416 px). The final state has 0 overflow and no horizontal scroll. The single frame reporting document `scrollWidth` over by ~350-416 px is a recorder artefact (my rAF callback runs before the runtime's first step and sees the final fit layout, which is never painted); no frame after it and no final state has horizontal overflow. Slow-motion captures (time scaled x0.04, `after/followup-*.png`) confirm the spill visually (pre and post) and its absence after the fix.
**Fix (kept inside the polish).** `runtime.js`: class `hm-morphing` on the canvas only while an animated morph runs (added in `go()` after the instant/reduced-motion return; removed in `finish()`, `fallback()` and, after the reviewer's note, `build()` so a resize/media change mid-morph cannot leave it on); `HomeMosaic.astro`: `.hm-morphing .hm-box { overflow: clip; }`. Text is clipped to its growing box during the morph only. No copy cut, fit guards and scroll/auto-scroll timing unchanged (clip does not change scrollHeight/clientHeight), reduced motion (instant, class never set) and no-JS unchanged.
**Evidence.** Timeline DE 1024 pre / polish / fixed: visible per-frame text overshoot 8 / 8 / 0 frames (the remaining counted frame is the unpainted artefact); reduced-motion timeline 0 frames; resize-during-morph and close paths leave no stuck class; `home-runtime.spec.ts` 15/15 (workers=1) on the build and on the served package; no five-repeat campaign, no full suite (legacy pricing batch still NOT GREEN).
