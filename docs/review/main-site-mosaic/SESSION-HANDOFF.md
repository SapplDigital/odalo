## M3 prototype revision 2 — irregular polygon mosaic (28 Oct 2026, after owner rejected the rectangular first geometry)

Seeds: 4 content seeds (hero + web/local/ads) with big weights r^2 (r 335-380) and ~250 decorative seeds on a jittered grid (seeded rng, fixed weights 400-16000, rim kept around content), greedy-coloured sand/slate/coral so touching pieces differ; navy ground + 5px seams. Same seeds every load; nothing moves at rest. Text pieces are HTML placed inside the largest axis-aligned rectangle inscribed (22 unit margin) in each content polygon, so no text meets an acute corner; sizes follow canvas width (`--k`).
- **Decorative hover:** instant, synchronous. Hovered cell weight += 0.8*rho^2, whole diagram recomputed (~10 ms), so it grows ~1.11x linear while neighbours yield and the tiling stays fitted; content cells move by <7 units (inside the 22 margin). Hit-testing always uses the REST polygons (point-in-polygon), no dwell, no easing, mouse only. Leaving restores rest instantly. Content hover = slight brighten + picture zoom (no geometry).
- **Content open/close:** click anywhere on a closed piece, or its Explore button / Enter / Space. The piece's cell gets a bigger weight and moves down; everything below shifts down by dH (dH is grown until the real text, in whatever language, fits the cell's inscribed rectangle: secant search). Polygons, text rects and canvas height ease over 380 ms (resampled 24-point blend); reduced motion = immediate. Close button or Escape collapses, focus returns to that piece's button. Clicking/selecting inside revealed text never closes it. Links native. No JS: plain stacked flow with all details visible.
- **Checks (Edge pane, proportionate):** EN hover on a decorative cell: 1.112x linear, 1 target flip crossing a boundary each way, flip at the same place both directions (hit uses rest polygons); content area change 0.00% when not adjacent. EN open local/Escape/text-click: opens, stays open on detail clicks, Escape closes, focus on toggle, canvas 2240 -> 2570 -> 2240. DE 1440: rest + all three opens, 0 overflow. ES 1024 (k 0.8): rest 0 overflow, ads open 0 overflow, no horizontal scroll. DE 375 (narrow): no horizontal scroll, local opens (dH 420) with 0 overflow.
